NOWSHERA FAMILY CLINIC — QUICK START

1. Extract the ZIP fully.
2. Install Python 3.11+ with "Add Python to PATH" if needed.
3. Double-click START-WINDOWS.bat.
4. Read the generated password in the Notepad window.
5. Open http://127.0.0.1:5000 if the browser does not open.
6. Keep the server window open.
